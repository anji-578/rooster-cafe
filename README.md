# Rooster Cafe

Cafe website + **Cafe OS** (customer / kitchen / biller) for Rooster, Koramangala.

## Local

```bash
cd web
npm install
npm run dev
```

- Site: http://localhost:3000  
- Admin QRs: http://localhost:3000/admin  
- Kitchen: http://localhost:3000/kitchen  
- POS: http://localhost:3000/pos  

See `web/CAFE_OS.md` for the full operations guide.

Domain: **www.roostercafe.in**
