# Rooster Cafe OS

End-to-end cafe operations for **Rooster** (Koramangala): customer table QR ordering, kitchen display, biller POS, snooker timed billing on **S1**, loyalty/feedback, **thermal bill printing**.

## Quick start (local)

```bash
cd web
npm install
npm run dev
```

In a second terminal (thermal / mock printer):

```bash
cd web
npm run print-agent
```

Open http://localhost:3000

### Staff apps
| Role | URL |
|------|-----|
| Admin / QRs / printer settings | http://localhost:3000/admin |
| Kitchen (chef) | http://localhost:3000/kitchen |
| POS (biller) | http://localhost:3000/pos |
| Customer table | http://localhost:3000/t/{token} (from Admin QR) |

## Flows

1. **Admin** → print QRs for T01–T25 + **S1**; set print agent URL
2. Guest scans table QR → orders food (S1 can also **Start playing** snooker)
3. **Kitchen** sees tickets by priority / age
4. Guest **Request bill** (auto-ends snooker timer and adds time charge)
5. **POS** selects table → apply loyalty discount → Cash/UPI/Card → **auto thermal print**
6. **Reprint** from Recent bills (laptop or tablet on cafe Wi‑Fi)
7. Guest leaves feedback → 4–5★ unlocks next-visit reward %

### Snooker (S1)
- Separate timed billing: Start → live timer → End → line item `minutes × ₹/min`
- Food orders still tagged to S1 and delivered there
- Default rate: **₹5/min** (configurable in store settings)

## Thermal printing (laptop + tablet)

Bills are generated by the website (text + ESC/POS). A small **print agent** on the cafe LAN talks to the physical printer. Any laptop/tablet on Wi‑Fi can tap Print.

```
POS (laptop/tablet) → /api/cafe print-bill → receipt JSON
        ↓
  Print agent :9101  →  ESC/POS  →  thermal printer (USB via PC, or LAN :9100)
```

### Setup
1. Start agent: `npm run print-agent` (MOCK writes files to `print-agent/out/`)
2. Live network printer:
   ```bash
   PRINTER_HOST=192.168.1.50 PRINTER_PORT=9100 HOST=0.0.0.0 npm run print-agent
   ```
3. **Admin** → set Print agent URL to `http://<cafe-pc-lan-ip>:9101` (not only `127.0.0.1` if using tablets)
4. Tap **Test agent** from the tablet to confirm
5. Pay on POS → bill auto-prints; use **Print bill** / Recent bills to reprint

Long bills (many items + snooker minutes) print as continuous roll — no page limit.

Browser preview remains as fallback if the agent is offline.
